## Описание

Выполнение лабораторной работы № 4 «Функциональное программирование на Python».

Цель — освоить функции высшего порядка, lambda, map, reduce, генераторы и композицию функций.

Вариант 1: средняя сложность — задания **1, 3, 5**; повышенная сложность — задания **1, 4**.

Каждое задание находится в отдельном модуле с функцией `main()` и защитой `if __name__ == "__main__"`. При импорте демонстрации не запускаются. Вычисления отделены от вывода результатов.

## Требования и проверка стиля

Python 3.9 или выше. Для выполнения заданий достаточно стандартной библиотеки Python.

Для проверки оформления установите flake8:

```bash
python -m pip install flake8==7.3.0
python -m flake8 .
```

Подключите Git-хук из папки репозитория:

```bash
git config core.hooksPath hooks
chmod +x hooks/pre-commit
```

В Windows команды выполняются в Git Bash. Хук проверяет все Python-файлы рабочей папки и отменяет коммит при ошибках flake8.

## Выполненные задания

### Средн.1 — задание 1: квадраты чисел от 1 до 10 с map

Файл `squares.py`. Функция `calculate_squares()` передаёт в `map()` lambda-функцию возведения в квадрат и числа из `range(1, 11)`. `map()` применяет функцию к каждому числу, а `list()` собирает результаты в список.

```bash
python squares.py
```

Результат: `[1, 4, 9, 16, 25, 36, 49, 64, 81, 100]`.
